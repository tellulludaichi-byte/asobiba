# 東大生の遊び場+α 公式サイト

[**https://utalpha.com**](https://utalpha.com)

「東大生の遊び場+α(プラスアルファ)」は、いろいろなサークルのメンバーが個人として集まるコミュニティです。このリポジトリは、その公式サイトのソースコードです。企業の公式サイトに寄せた構成で、イベント告知・過去の活動・サークルとのつながり・協賛企業を紹介しています。

運営メンバーが無理なく更新し続けられるように、**フレームワークもビルドも使わず、データのファイルを1つ編集するだけで内容を更新できる**ことを軸に作っています。

## デザインで大切にしたこと

**開いた瞬間に「遊び場」の雰囲気が伝わり、かつ硬くならないこと**を一番の軸にしました。団体の公式サイトとして信頼感は必要ですが、整いすぎると、実際のコミュニティの空気とずれてしまうからです。

- **最初に見せるのは、実際のメンバーの写真**: トップは、交流会の集合写真を全面に敷いています。見出しは「サークルの垣根を越えた、東大生の遊び場。」。説明より先に、人が集まっている様子が目に入るようにしました。
- **構成はきちんと、写真の見せ方は遊び心を**: ページの構成は企業サイトに寄せて整え、活動写真だけは、ポラロイド風(白フチ+マスキングテープ+少し傾ける)で並べています。傾きは一枚ごとに変え、ホバーするとまっすぐに戻ります。きれいに揃えすぎないことで、堅い印象をやわらげています。
- **色は抑えて、写真を主役にする**: 文字や見出しはモノクロ基調で、色を持つのはロゴと写真だけにしています。マスキングテープの色だけは、ロゴの色を使っています。色数を絞ることで、賑やかな写真が散らからずに映えます。
- **それっぽい装飾は入れない**: 意味のないグラデーションや透かし文字など、中身のない飾りは使っていません。雰囲気は、実際の活動の写真で伝えます。
- **読みやすさ**: 本文は一行の長さを抑え、余白と字間を広めにとっています。フォントはOS標準の日本語フォント(ヒラギノ・游ゴシック・メイリオ)にして、Webフォントの読み込みを省き、表示を軽くしました。

## 実装上の工夫

- **ビルド不要の静的サイト**: 素の HTML・CSS・JavaScript だけで構成しています。`public/` をそのまま Cloudflare Workers で配信します。リンクは相対パスなので、`index.html` をブラウザで直接開いて確認することもできます。
- **データと表示の分離**: 更新頻度の高い内容は、`events-data.js`(イベント・活動写真)、`circles-data.js`(サークル)、`sponsors-data.js`(協賛企業)に分けてあります。HTML を触らずに、1ブロック足すだけで反映されます。
- **掲載の承諾を前提にしたデータ設計**: サークルと協賛企業は、掲載の承諾を得たものだけを `approved: true` として表示します。さらに、配信されるファイルは誰でもソースを表示して読めるため、承諾待ちの名前はそもそもファイルに置かない運用にしています。
- **掲載期限による自動の取り下げ**: イベントに `until: "2026-11-03"` のように期限を付けると、その日を過ぎたら自動でトップから消えます。判定は閲覧者の端末の時計ではなく、日本時間で行います(`public/expire.js`)。
- **0件でも成立する画面**: イベントやサークル、協賛が0件のときの表示も用意してあり、データが空でもページが崩れません。

## 使っている技術

| 項目 | 内容 |
|---|---|
| 言語 | HTML / CSS / JavaScript(フレームワークなし) |
| ホスティング | Cloudflare Workers(静的アセットの配信) |
| デプロイ | Wrangler CLI |
| ドメイン | Cloudflare Registrar |

## 技術選定の理由

学生団体のサイトなので、**作る人より、更新し続ける人に合わせて**選びました。

| 選んだもの | 理由 |
|---|---|
| フレームワークなしの HTML / CSS / JS | ページ数は少なく、更新の中心はイベントや写真の追加です。この規模にフレームワークとビルドは過剰で、依存が増えるほど、メンバーが入れ替わったときに引き継ぎにくくなります。ビルド不要なら、ファイルを開いてそのまま確認でき、壊れる原因も減らせます。 |
| 更新内容をデータファイルに分離 | 更新するたびに HTML を触らずに済みます。HTML に詳しくない運営メンバーでも、1ブロック足すだけで反映できます。構造がそのまま CMS に移せる形なので、将来の入れ替えも楽です。 |
| Cloudflare(Registrar・DNS・Workers) | ドメインの取得、DNS、配信を1つの管理画面にまとめられます。デプロイは `wrangler deploy` の1コマンドで、費用はほぼドメイン代(年間 約1,600円)です。 |
| GitHub での履歴管理 | 変更の履歴を残し、誰がいつ何を変えたかを追えます。将来は、push で自動デプロイしたり、ブラウザから更新できる CMS(Decap CMS など)をつないだりすることも想定しています。 |

**検討して、いまは見送ったもの**

- **CMS(microCMS・Decap CMS など)**: 運営メンバーが実際に更新する場面を見てから、必要かどうかを判断する方針です。先に入れると、使われない仕組みを維持することになるためです。
- **お知らせ(News)ページ**: 更新の見込みが立ってから追加します。

## ディレクトリ構成

```
.
├── public/                  配信されるファイルはすべてここ
│   ├── index.html           トップ(イベント情報・今までの活動・協賛企業)
│   ├── events/              過去のイベント一覧
│   ├── about/               理念・進行中のプロジェクト・概要
│   ├── circles/             サークルとのつながり
│   ├── contact/             お問い合わせ
│   ├── events-data.js       イベントと活動写真のデータ
│   ├── circles-data.js      サークルのデータ
│   ├── sponsors-data.js     協賛企業のデータ
│   ├── expire.js            掲載期限を過ぎた表示を取り下げる
│   ├── style.css            全ページ共通のスタイル
│   └── images/              ロゴ・写真・フライヤー
├── wrangler.jsonc           Cloudflare Workers の設定
├── SPEC.md                  仕様・デザイン方針・決定事項のログ
└── CLAUDE.md                開発時の方針
```

## ローカルで確認する

ビルドは要りません。次のどちらかで確認できます。

- `public/index.html` をブラウザで直接開く
- Node.js を入れて `npx wrangler dev` を実行する(本番に近い配信で確認できます)

## 内容を更新する

### イベントを告知する

`public/events-data.js` の `UPCOMING_EVENTS` に、1ブロック追加します。

```js
{
  badge: "11/14(土)開催",
  until: "2026-11-14",            // この日を過ぎたら自動でトップから消える
  title: "イベント名",
  description: "イベントの紹介文。",
  details: [
    ["日時", "11/14(土)13:00–19:00"],
    ["場所", "会場名"],
    ["参加費", "無料"],
  ],
  flyers: [{ src: "images/flyer-1114-example.jpg", alt: "フライヤーの説明" }],
  note: "補足があれば",
},
```

### 終わったイベントを活動の記録に移す

`PAST_ACTIVITIES` の先頭に1行足します。トップには新しい順に6件、`/events` には全件が表示されます。写真は任意で、なければ日付と名前だけの行になります。

```js
{ date: "11/14", title: "イベント名", src: "images/event-1114-example.jpg", alt: "写真の説明" },
```

### サークルや協賛企業を載せる

掲載の承諾を得てから、`circles-data.js` または `sponsors-data.js` に `approved: true` で追記します。

### 画像を追加する

`public/images/` に入れます。ファイル名は半角英数字とハイフンにし、1枚 500KB 以下を目安に縮小します。写真に写る人は、掲載の了承を得てから載せます。

## デプロイ

```sh
npx wrangler login      # 初回のみ
npx wrangler deploy
```

`public/` の中身がそのまま Cloudflare に送られます。公開したくないファイルは `public/` に置かないでください。

## このリポジトリに含めていないもの

次のものは、公開の対象外としています。

- 会則・名簿・元画像などの内部資料(`docs/` は、説明の README を除いて git の管理外です)
- 掲載の承諾を得ていないサークルや人の情報
- メールアドレスなどの個人の連絡先
